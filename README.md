# ماي فون ستور 📱

موقع متجر إكسسوارات هواتف مبني بـ **HTML + CSS + JavaScript**، مع:

- 🛒 سلة مشتريات وكوبونات خصم
- 💬 **إرسال الطلب على واتساب** المحل مباشرة
- 👤 تسجيل الزبائن بالاسم ورقم الهاتف
- 📊 **لوحة تحكم للمدير** (`admin.html`):
  - إضافة / تعديل / حذف / إخفاء المنتجات مع رفع الصور
  - التخفيضات (لمنتج أو لقسم كامل) وكوبون العرض مع تاريخ الانتهاء
  - عدد الزيارات والزوار وزيارات اليوم ورسم بياني لآخر 14 يوماً
  - قائمة الزبائن: الاسم، الهاتف، نوع الجهاز والموديل، النظام، المتصفح، عدد الزيارات والطلبات، مع مراسلة واتساب وتصدير Excel
  - إدارة الطلبات وتغيير حالتها (جديد / مؤكد / تم التسليم / ملغي)

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية للمتجر |
| `admin.html` | لوحة تحكم المدير |
| `js/config.js` | **الإعدادات: رقم الواتساب، Firebase، العملة** |
| `js/db.js` | حفظ وقراءة البيانات + معرفة جهاز الزائر |
| `js/script.js` | برمجة المتجر |
| `js/admin.js` | برمجة لوحة التحكم |
| `firestore.rules` | قواعد حماية قاعدة البيانات |

## طريقة العمل

### 1) الوضع التجريبي (يعمل فوراً)
افتح `index.html` للمتجر و `admin.html` للوحة التحكم (كلمة المرور: `admin123`، غيّرها من الإعدادات).

⚠️ في هذا الوضع تُحفظ البيانات في **متصفح الجهاز نفسه فقط**، أي أن لوحة التحكم لن ترى زيارات وطلبات الزبائن من أجهزتهم. للاستخدام الحقيقي فعّل Firebase.

### 2) الوضع الحقيقي مع Firebase (مجاني)
1. ادخل إلى <https://console.firebase.google.com> وأنشئ مشروعاً جديداً.
2. من **Build ← Firestore Database** اضغط Create database.
3. من **Build ← Authentication ← Sign-in method** فعّل **Email/Password**، ثم من تبويب **Users** أضف حساب المدير (بريدك وكلمة مرور قوية).
4. من **Firestore ← Rules** الصق محتوى ملف `firestore.rules`، وغيّر `admin@example.com` إلى بريد المدير، ثم Publish.
5. من **Project settings ← Your apps** أضف تطبيق Web (`</>`) وانسخ `firebaseConfig`.
6. الصقه في `js/config.js` مكان `const FIREBASE_CONFIG = null;`.
7. ارفع الموقع على استضافة (مثلاً GitHub Pages أو Firebase Hosting أو Netlify).
8. افتح `admin.html` وسجّل الدخول ببريد المدير. أول دخول يضيف المنتجات الافتراضية تلقائياً.

### رقم الواتساب
غيّره من لوحة التحكم ← الإعدادات (بالصيغة الدولية مثل `218912345678`).
